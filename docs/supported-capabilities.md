# Capability matrix

| Capability | Status |
|---|---|
| Typed protocol and strict validation | supported |
| Observation-bound expiring permits | supported |
| SQLite hash-chain journal | supported |
| Native Windows UIA/input | not implemented; requires Windows validation |
| Browser isolation/CDP | not implemented |
| Electron UI/IPC | not implemented |
| Voice/emergency stop | not implemented |
| Credentials, MFA, UAC, secure desktop | unsupported; user intervention required |
